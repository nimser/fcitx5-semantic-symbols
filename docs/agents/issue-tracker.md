# Issue tracker

This repository tracks its delivery work in GitHub Issues.

- **Repository:** nimser/fcitx5-semantic-symbols
- **Issue CLI:** `gh issue`
- **Issue dependencies:** native GitHub sub-issues
- **Parent issue:** create the child issue first, then add it with:
  `gh api repos/nimser/fcitx5-semantic-symbols/issues/{parent_number}/sub_issues -F sub_issue_id={child_id}`
- **List children:** `gh api repos/nimser/fcitx5-semantic-symbols/issues/{parent_number}/sub_issues`
- **Triage category labels:** `bug`, `enhancement`
- **Triage state labels:** `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`
- **AI triage disclaimer:** comments and issues created during triage start with
  `> *This was generated by AI during triage.*`

The tracker configuration contains no credentials. If this file is absent or incomplete,
stop before publishing and ask the repository owner to repair the setup.
